# 麦当当惊喜官

生日、纪念日、道歉、表白、异地送礼——你说场合，它用麦当劳把事办了。

## 何时使用

用户出现以下任一意图时触发本 Skill：

- **纪念日**：周年、在一起 X 天、结婚纪念日、入职周年……
- **生日**：朋友 / 伴侣 / 家人生日，想在麦当劳制造小惊喜
- **道歉**：惹对象/朋友生气，想"先送一份麦当劳到位"
- **表白 / 求交往**：想用一顿轻松的饭开场
- **异地惊喜**：给远方的朋友 / 家人远程点一份
- **关键词信号**：惊喜、仪式感、纪念日、周年、生日、道歉、哄、表白、告白、crush、异地、送礼

## 前置条件

- 已配置麦当劳 MCP Server（`mcd-mcp`），配置见 `mcp-config.example.json`
- 已获取有效 MCP Token

## 需要用户补充的信息（缺失时主动询问）

| 信息 | 用途 | 是否必须 |
|---|---|---|
| 场合类型 | 决定文案风格与套餐基调 | 必须 |
| 对象 / 关系 | 决定话术口吻（恋人 / 朋友 / 家人） | 必须 |
| 预算 | 控制套餐总价 | 建议 |
| 同城还是异地 | 决定下单方式 | 必须 |
| 异地收货地址 | 异地场景必需 | 仅异地 |
| 对方忌口 / 偏好 | 排除不合适的餐品 | 建议 |

## 调用流程（七步）

```
用户输入场合
   ↓
[1] campaign-calendar        查询当月活动/联名/限定，找与场合契合的
   ↓
[2] 定位门店（二选一）
   ├─ 同城 → query-nearby-stores（就近门店）
   └─ 异地 → delivery-query-addresses / delivery-create-address
             → delivery-query-stores（确认对方地址可配送）
   ↓
[3] query-meals              拉取该门店在售餐品
   ↓
[4] query-meal-detail        查看套餐详情与可替换项，组合"惊喜套餐"
   ↓
[5] calculate-price          计算总价（含可用优惠券），判断是否超预算
   ↓
[6] 生成"惊喜方案卡"（套餐 + 总价 + 仪式感话术 + 是否超预算）
   ↓
[7] 用户确认 → create-order  创建订单，返回支付链接
```

## 下单参数组装要点（实测，2026-10-10）

> 以下为真实联调踩坑结论，组装 `calculate-price` / `create-order` 的 `items` 时必须遵守。

1. **`items` 里的字段名是 `productCode`，不是 `code`**
   错误：`{"code":"9900016076","quantity":1}` → 返回 `productList: []`、价格 0
   正确：`{"productCode":"9900016076","quantity":1, ...}`
2. **套餐必须传 `roundList`**，组装自 `query-meal-detail` 返回的 `rounds`：
   - `round`（string）= `rounds[].id`
   - `comboItemList[].code` = 该轮选中项的 `choices[].code`
   - 示例见下。
3. **价格单位是「分」**：`calculate-price` 返回的 `price`/`originalPrice`/`discount` 均为分，展示时 ÷100。
4. **`beCode` 传不传**：`beType=1`（到店自提）门店无 beCode，后续不传；`orderType=1` 时 `query-meal-detail` 不能传 beCode。
5. **取餐方式**：`calculate-price` 返回 `takeWayList`（`eat-in` 堂食 / `locker-in` 外带），到店下单时需携带，需让用户先选。
6. **分时段预约**：门店 `reservationTimeOptions` 含早餐/午餐/下午茶/夜市/宵夜；预约场景需传 `reservationDate`（`yyyy-MM-dd HH:mm`）。

```json
{
  "productCode": "9900016076",
  "quantity": 1,
  "roundList": [
    { "round": "1", "comboItemList": [ { "code": "521962", "quantity": 1 } ] },
    { "round": "2", "comboItemList": [ { "code": "521965", "quantity": 1 } ] },
    { "round": "3", "comboItemList": [ { "code": "521959", "quantity": 1 } ] }
  ]
}
```

## 仪式感话术库（输出时按场合选用，可自由改写）

> 本节为话术素材的权威来源；程序化按单位选用的参考实现见 `scripts/surprise_logic.py`。

### 纪念日
- 「X 周年快乐。今天的第一份仪式感，就用麦当劳补上。」
- 「和你们在一起的第 X 天，想吃一顿不用挑店的饭。」

### 生日
- 「生日快乐！愿望可以慢慢想，薯条要趁热吃。」
- 「今年的愿望先不贪心，先把你喂饱再说。」

### 道歉
- 「对不起，这份麦当劳先替我到位，人随后就到。」
- 「是我错了。麦辣鸡翅的辣，都比不过我现在的心急。」

### 表白
- 「不知道送什么，就先送你一顿我们都喜欢的麦当劳吧。」
- 「如果你愿意，这顿之后，我们可以常一起吃。」

### 异地惊喜
- 「人还没到，饭先到了。」
- 「距离有点远，但这份心意是热的。」

> 使用原则：话术要**贴场合、不油腻、不堆砌**；能结合当月活动（联名/限定）时优先融入，增强"当下专属"感。

## 输出规范：惊喜方案卡

每次给方案时，统一按以下结构输出：

```
🍔 惊喜方案 · {场合名称}
────────────────────
套餐组合：
  · {餐品 1}（{说明/替换项}）
  · {餐品 2}
  · {餐品 3}
合计：{总价} 元（{是否含优惠券，省 X 元}）
预算核对：{未超 / 已超预算 X 元}
仪式话术：
  「{话术}」
活动亮点：{若有契合的当月联名/限定，点出；没有则写"今日无契合活动，以常规套餐呈现"}
取餐方式：{堂食 / 外带}
────────────────────
确认下单请回复「下单」；想调整套餐请告诉我。
```

**真实示例（2026-10-10 实测，西安交大店）**：

```
🍔 惊喜方案 · 表白
────────────────────
套餐组合：
  · “我就喜欢”鸡薯双全盒（5块心形薯饼 + 5块麦乐鸡 + 韩式辣椒黄油蘸酱）
  · 蓝莓爆爆珠麦旋风
合计：31.9 元（现价，原价 46 元）
预算核对：未超预算
仪式话术：
  「不知道送什么，就先送你一顿我们都喜欢的麦当劳吧。
    这份里有 5 块心形薯饼——你看，连薯条都是爱你的形状。」
活动亮点：本月麦当劳联动 G-DRAGON，韩式蘸酱上新，鸡薯双全盒限时 15.9 元起
取餐方式：堂食
────────────────────
确认下单请回复「下单」；想调整套餐请告诉我。
```

## 异常与降级

| 情况 | 处理方式 |
|---|---|
| 当月无契合活动 | 用常规套餐呈现，活动亮点写"今日无契合活动" |
| 超预算 | 给出 1 套低配方案（降档餐品），并标注节省金额，由用户选 |
| 异地地址不可配送 | 提示不可配送，改推"到店自取"或"就近换店" |
| 工具返回空 / 超时 | 明确告知"未取到"，**严禁编造**餐品、价格、活动 |
| 触发限流（429） | 降低调用频率，提示稍后重试 |
| 餐品价格取不到 | 标注"价格为实时接口返回，以支付页为准"，**不填估算价** |

## 边界

- 下单前**必须**向用户确认套餐内容、金额与收货地址，获明确同意后才调用 `create-order`
- **不代替用户完成支付**，仅返回支付链接
- 餐品信息、价格、活动以 MCP 实时返回为准；**取不到的数据一律标注「未取到」，绝不伪造**
- 本 Skill 为参赛作品，非麦当劳官方产品
